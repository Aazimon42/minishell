# minishell

## Description

Minishell is a project where students build a minimal Unix shell in C, reproducing the core behavior of bash.
It handles command parsing, environment variable expansion, builtin commands, redirections, pipes, heredocs, and signal handling.

## Instructions

### Compilation

Compile the project using:

```bash
make
```

### Execution

Run the program by passing no arguments:

```bash
./minishell
```
